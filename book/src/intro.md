# Rust 웹프로그래밍 과정 소개

Rust 프로그래밍 과정은 Rust를 처음 접하시는 분들 보다는 프로그래밍 언어를 한번이라도 접했봤다고 가정합니다. 기본 제어흐름, 변수 타입 등에 대한 기초지식을 요구합니다. 시스템 프로그래밍보다는 웹 프로그래밍에 초점을 맞추었습니니다.

- Rust 
- Leptos
- Axum

각 과정은 1부 시작하기(quick start)와 2부 활용하기(과제 수행형) 편으로 구분됩니다. [유튜브](https://youtube.com/playlist?list=PLOPw593iCLL4&si=y8wb0qP7hKa0x-X1)에서 영상을 시청할 수 있습니다.
